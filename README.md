# KIHO Story v2 무료 업그레이드

GitHub Pages 저장소의 루트에 ZIP 안의 6개 파일을 **압축 해제한 상태로** 업로드하세요. 기존 파일을 덮어씁니다. URL은 유지됩니다. 기존 앱에 저장한 데이터는 지우지 않습니다.

금색 아이콘은 새로 설치할 때 표시됩니다. 기존 설치 아이콘은 캐시 때문에 그대로일 수 있어 새 버전 배포가 완료된 뒤 홈 화면 앱 제거 후 Chrome에서 다시 설치해야 할 수 있습니다. 저장한 분석 데이터가 있다면 먼저 텍스트로 내보내기 하세요.

주소 입력 후 '주소로 AI 분석 시작'을 누르면 분석 지시문을 복사하고 ChatGPT를 엽니다. ChatGPT에서 붙여넣기 및 전송이 필요합니다. GitHub Pages는 나무위키 내용을 자동 수집하거나 ChatGPT Plus 대화를 자동 호출할 수 없습니다. 나무위키 접근이 실패하면 본문을 복사해 앱에 붙여넣으세요. 외부 출처가 없는 주장은 검증됨으로 처리하지 마세요.
