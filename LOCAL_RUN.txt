KIHO Story Research — 무료 로컬 수집
1. Python 3 설치 (추가 패키지 불필요)
2. 이 폴더에서 터미널 실행: python3 collector.py
3. 브라우저에서 http://127.0.0.1:8765 접속
4. 나무위키 URL 입력 후 '해당 문서 본문·각주 자동 수집' 클릭
5. 수집 원문 확인 후 요청문 복사 → ChatGPT에 붙여넣기
주의: 나무위키 접속 차단, 동적 렌더링, 접힌 내용, 각주 구조 변경 시 완전 수집 불가. 성공 메시지는 모든 각주를 확보했다는 뜻이 아님.
기존 아이콘, 앱 저장 데이터 키, 다른 프로젝트는 변경하지 않았습니다.
